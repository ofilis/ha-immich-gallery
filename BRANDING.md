# Branding and trademark notice

The Immich Gallery logo combines a five-color house/aperture silhouette with a
simple mountain-and-sun gallery symbol. It is used consistently in the GitHub
README, HACS, and Home Assistant.

The mark is not an official logo of Immich or Home Assistant. It does not use
Home Assistant's official three-node network symbol. The house and gallery
composition identifies this independent integration without implying
endorsement.

## Ownership and non-affiliation

Immich Gallery is an independent community project and is not affiliated with,
sponsored by, or endorsed by Immich, FUTO, Home Assistant, the Open Home
Foundation, or HACS.

Immich and Home Assistant names and trademarks belong to their respective
owners. References to them describe compatibility and project purpose.

## Included files

The repository uses one logo with transparent RGBA PNG sizes required by each
surface. Only the colored logo artwork remains visible; exterior and internal
neutral-white areas are transparent.

- `assets/logo.png`: README header artwork
- `assets/icon-256.png`: 256 × 256 icon source
- `assets/icon-512.png`: 512 × 512 icon source
- `custom_components/immich_gallery/brand/icon.png`: 256 × 256
- `custom_components/immich_gallery/brand/icon@2x.png`: 512 × 512

The runtime integration does not download branding from an external service.
