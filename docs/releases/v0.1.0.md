# Immich Gallery 0.1.0

The first public release of Immich Gallery adds privacy-conscious rotating
Immich images to Home Assistant.

## Highlights

- Random images from the entire Immich library, favorites, or selected albums.
- A separate Home Assistant image entity for every enabled source.
- A configurable refresh interval from 1 to 60 minutes.
- Per-source recent-image history to reduce visible repeats.
- HTTPS, local HTTP, reverse-proxy paths, Tailscale IP addresses, and MagicDNS
  hostnames.
- Immich-generated browser-safe previews for HEIC, HEIF, RAW, TIFF, and other
  source formats supported by Immich.
- Editable host, API key, TLS verification, sources, repeat window, and refresh
  interval through the integration's Configure screen.

## Setup and entity improvements

- Whole-library and favorite sources now require explicit selection.
- Deselecting a source removes its obsolete entity-registry entry instead of
  leaving it listed as unavailable.
- The repeat-window description now explains that recent images are remembered
  separately for every source.
- The refresh-interval description explicitly documents its 1–60 minute
  range.
- The integration interface and repository documentation are English-only.

## Privacy and security

- API keys are sent only through the `x-api-key` header.
- Redirects are not followed, preventing credential forwarding to another
  origin.
- TLS verification is enabled by default.
- Original assets are not downloaded.
- Preview responses are restricted to supported image types and 20 MiB.
- Diagnostics and logs exclude credentials, private hosts, media identifiers,
  filenames, EXIF data, and image content.
- No telemetry, analytics, cloud relay, or third-party runtime service is used.

## Compatibility

- Requires Home Assistant 2026.4 or newer.
- Uses an independent `immich_gallery` domain and can coexist with Home
  Assistant's built-in Immich integration.
- Installation is available through HACS as a custom repository while
  default-library admission is pending.
