# Immich Gallery 0.1.1

This maintenance release prepares Immich Gallery for submission to the default
HACS library and records the exact cause of missing icons in HACS 2.0.5.

## HACS publication readiness

- Adds regression tests for the HACS repository structure, required manifests,
  local brand assets, and validation workflow.
- Documents the verified default-library requirements, release ordering,
  alphabetic list position, and pull-request checklist.
- Confirms that HACS does not require README screenshots for integrations.
  Immich Gallery continues to publish no banner, personal photo, or library
  screenshot.

## Icon behavior

The bundled 256 × 256 and 512 × 512 Immich flower icons are valid and Home
Assistant displays them correctly.

HACS 2.0.5 still uses the legacy public brand CDN in its repository dashboard
and update entity, so those HACS views can show **Icon not available** for
custom integrations that package local brand assets. This is an upstream HACS
limitation, not a missing file in Immich Gallery. The relevant HACS fixes have
not yet shipped.

Default-library admission can proceed because its brand validator already
accepts the local `brand/icon.png` file.

## Integration metadata

- Removes an unused optional loading dependency on Home Assistant's built-in
  `immich` integration.
- Keeps the independent `immich_gallery` domain and all existing runtime
  behavior unchanged.

## Compatibility

- Requires Home Assistant 2026.4 or newer.
- No configuration migration is required from 0.1.0.
