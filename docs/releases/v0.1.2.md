# Immich Gallery 0.1.2

This visual and documentation update gives Immich Gallery a clearer project
identity and a more useful first page for new users.

## New project logo

- Adds the selected five-color house-and-landscape logo to the repository.
- Uses matching 256 × 256 and 512 × 512 PNG icons for Home Assistant and HACS.
- Keeps all branding files local to the integration; no runtime image request is
  added.

## Improved README

- Adds direct HACS and Home Assistant setup buttons.
- Focuses the front page on installation, supported image sources, dashboard
  use, later configuration, privacy, and security.
- Removes internal submission history and maintainer-only implementation detail
  from the user-facing introduction.
- Uses the project owner's GitHub handle in the MIT copyright notice.

## Compatibility

- Requires Home Assistant 2026.4 or newer.
- No configuration migration is required from 0.1.1.
- Runtime gallery behavior is unchanged.
