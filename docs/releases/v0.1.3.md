# Immich Gallery 0.1.3

This patch corrects the transparency of the Immich Gallery logo introduced in
0.1.2.

## Transparent branding

- Converts the repository logo and bundled 256 × 256 and 512 × 512 icons to
  true RGBA PNG files.
- Removes the exterior white background and every internal neutral-white
  separator, leaving only the colored logo artwork visible.
- Keeps the repository icon sources byte-identical to the local Home Assistant
  brand files.
- Adds regression checks that require an alpha channel on every published PNG.

## Compatibility

- Requires Home Assistant 2026.4 or newer.
- No configuration migration is required from 0.1.2.
- Runtime gallery behavior is unchanged.
