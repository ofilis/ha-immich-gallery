# Immich Gallery 0.1.4

This patch fixes the project branding displayed in the HACS repository
information page.

## HACS README images

- Uses an absolute raw GitHub URL for the Immich Gallery logo instead of a
  repository-relative image path.
- Renders the MIT license badge as a direct image without a relative wrapper.
- Adds regression coverage for the HACS-safe logo and license badge URLs.

## Compatibility

- Requires Home Assistant 2026.4 or newer.
- No configuration migration is required from 0.1.3.
- Runtime gallery behavior is unchanged.
