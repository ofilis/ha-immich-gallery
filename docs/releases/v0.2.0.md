# Immich Gallery 0.2.0

## Control your slideshow from Home Assistant

- **Next image:** Every selected album, favorites source, and library source now
  has its own button. Press it to request a new random preview without waiting
  for the timer or changing the other sources. Also works in automations.
- **Refresh interval:** Set the shared interval using a 1–60 minute slider on the
  Immich Gallery device page.
- **Automatic slideshow:** Turn off timed changes while keeping Next image
  available. Turn it on to resume after the selected interval.

Playback settings are saved, synchronized with Configure, and applied without
reloading the integration. The existing read-only API key permissions are enough.

## Upgrade

Update in HACS and restart Home Assistant. The new controls appear on the existing
Immich Gallery device. Existing installations keep automatic playback enabled and
retain their configured interval. No reconfiguration is required.

Next image preserves the automatic schedule and depends on the Immich connection
to fetch a preview. If an update is already running, wait for it to finish before
pressing again. A failed manual request keeps the previous image visible.

The playback setting survives restarts, but cached image bytes do not: one initial
image is fetched per source after restarting, including while playback is paused.
