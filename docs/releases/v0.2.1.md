# Immich Gallery 0.2.1

## Keep your photos visible through temporary interruptions

- A brief connection failure or unusable preview no longer makes a previously
  working image unavailable for an entire slideshow cycle. The last good photo
  stays visible until a replacement is successfully downloaded.
- Failed sources get up to two short retries: after 30 seconds, then another
  60 seconds. Other sources keep their normal timing. The regular slideshow
  interval takes precedence if it is due sooner, and Immich rate-limit delays
  are respected.
- Pausing the slideshow or unloading the integration cancels pending retries.
  Manual Next image controls continue to work as before.
- Image attributes now expose `image_stale` and `last_refresh_error`, so a cached
  photo is distinguishable from a fresh result without exposing private data.

During a prolonged outage, the last photo remains visible and retries return to
the configured interval. A source without a cached photo stays unavailable until
it can load one. Invalid API keys or missing permissions still require
reauthentication and clear cached previews; empty sources and non-retryable API
errors remain unavailable.

## Upgrade

Update to **v0.2.1** in HACS and restart Home Assistant. No reconfiguration or new
API permissions are required. Your selected sources and playback settings are
preserved.
